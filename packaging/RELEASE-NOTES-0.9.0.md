# v0.9.0 — EmuTV: Living-Room Mode comes to Linux

## 📺 EmuTV — Living-Room Mode

Emutastic now has a full controller-driven, big-screen couch interface — a
complete port of EmuTV to the Linux build. Drop onto the sofa, pick up a
controller, and browse and launch your whole library on the TV without touching
a keyboard or mouse.

### Highlights
- **Controller-first fullscreen UI** — a themed system carousel and game lists
  you drive entirely from the gamepad.
- **ES-DE theme engine** — renders EmulationStation Desktop Edition themes, with
  a built-in default theme plus in-app **theme browsing, downloading, and
  importing** of your own.
- **Fullscreen game launches** — anything you start from EmuTV opens cleanly
  fullscreen, no window chrome, and drops you right back to the couch shell on
  exit.
- **SteamGridDB artwork** — optional cover-art fetching to round out your
  library's box art (add your API token in Preferences).
- **Animated TV preview** and polished presentation throughout — aesthetics were
  treated as a first-class part of the feature.

### Getting in
- **Controller:** hold **L2 + R2 + L3 + R3** (both triggers + both sticks
  clicked) for ~2 seconds from the library.
- **Keyboard:** press **F9**.
- **Leaving a game:** hold the same controller chord briefly to quit back to
  EmuTV.

### Configuration
A new **Preferences → EmuTV** tab covers SteamGridDB, the navigation hotkeys, and
a reference for all the controller combos.

## Also in this release
- Fullscreen now strips all window chrome (title bar, caption buttons, rounded
  corners) on every core — toggle any windowed game with **F11**.
